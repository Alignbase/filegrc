# Noto Serif

The four static TrueType faces come from the hinted TTF directory of the [Noto Serif 2.015 release](https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSerif-v2.015). FileGRC embeds the faces it uses in each export. See OFL.txt for the upstream copyright notice and SIL Open Font License 1.1.
