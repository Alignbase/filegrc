# Secure Development Training

## Who must complete this

Assign this training to people who develop or materially change applications, infrastructure, deployment systems, or security-sensitive automation. Complete it within 30 days after starting a covered role or taking on covered duties.

## Required practices

- Design access checks at each trust boundary and deny access by default.
- Validate untrusted input and encode output for its destination.
- Keep credentials, tokens, and private keys in approved secret stores.
- Do not put production secrets or unnecessary production data in source, tests, logs, or development systems.
- Review material code and infrastructure changes before deployment.
- Test changes in proportion to their security and operational risk.
- Scan dependencies, source, and built artifacts where the toolchain supports it.
- Record the change, review, test result, deployment, and rollback method.
- Log security-relevant events without exposing secrets or unnecessary personal data.
- Report suspected vulnerabilities and security events immediately.

## Completion

Review the Information Security Policy and Data Protection and Handling Policy with this material. Record an attestation tied to the Git revisions reviewed. If a person's role does not meet the audience above, record that decision instead of a completion.
